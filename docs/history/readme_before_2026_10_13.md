## 操作表

### 視窗縮放

可拖曳視窗邊緣或最大化；最小獨立視窗為 **800×450**。以 1280×720 為設計基準，畫面隨視窗等比例縮放；不同長寬比會擴展地圖可見範圍，不會拉長角色或強制留 16:9 黑邊。

GUI 使用原生錨點定位：左側肖像固定靠左、底欄貼底、命令／技能靠右下、世界圓形小地圖靠右上，設定／戰果／倒數等彈窗置中。鏡頭邊緣捲動改用實際視域尺寸。場景 sprite 使用 nearest filtering，UI 文字仍以目標解析度繪製。

採自由比例縮放以適應任意視窗，**不是只允許 1×／2× 的整數像素模式**；非整數倍率下無法保證每個來源像素占相同數目的螢幕像素。

Godot 編輯器內嵌 Game 面板請選 **Stretch to Fit**，不要固定預覽倍率。更改後停止遊戲並重新執行。

本輪視窗與渲染檢查 **96 項通過**；點選回歸 **14 項通過**。見 [驗證記錄](docs/v2_validation.md)。

## 編隊與技能

| 角色 | 功能 |
| --- | --- |
| 行旅商人 | 主角、基本近戰 |
| 鐵衛 | 承傷近戰；爆雷擊 |
| 火銃手 | 遠程投射物；有機率消耗 MP 發動強化射擊 |
| 雷術師 | 指定地面雷擊範圍傷害 |
| 醫術師 | 友軍低於 62% HP 時自動恢復最危急目標 |
| 道術師 | 指定存活友軍補魔 |

技能超出射程時先走近，正式進入前搖才扣 MP。移動、停止或新命令可取消尚未釋放的技能；已扣除的 MP 不退還。已射出的投射物仍會完成。傷害和技能釋放由 60 Hz 固定更新決定，動畫為其呈現。

敵方包含近戰妖獸、弓兵、黑甲精英和可施放範圍技能的赤魂首領。草原、山道和洞窟擁有不同的障礙分佈；不可達目標會停在最近可達處並提示。

## 可保存的手感設定

可調項目：移速倍率、轉向、索敵倍率、攻擊前搖、施法倍率、連射間隔、碰撞半徑、鏡頭速度、停止後索敵延遲，以及 GUI 字體倍率。

按住連射、Ctrl 預約連射與 E 預約功能可分別啟閉。操作設定保存到 `user://combat_feel.cfg`；獨立養成／背包保存到 `user://party_progress.dat`，與設定分離，保留上一版 `.bak`。

設計基準為 1280×720，其他視窗尺寸保持比例；1920×1080 可直接使用。中文字型由 Windows Microsoft JhengHei 或系統 CJK fallback 提供。

## 架構與擴充

- `common/data/`：UnitDefinition、SkillDefinition、EncounterDefinition、CombatFeelProfile；各兵種／技能／遭遇的 .tres 在對應功能資料夾。
- `features/world/`：平面邏輯網格、NavigationRegion2D、TileMapLayer 與場景物件。
- `features/units/`：CharacterBody2D、NavigationAgent2D、獨立 Vitals 與狀態機；遠端 Inspector 可查看當前狀態。
- `features/battle/`：統一 `issue_command(command)`、選取、編隊、施法順序、固定更新和場景流程。
- `features/presentation/`、`features/ui/`：八方向 sprite 動畫、技能／命中特效、古典 HUD、小地圖與設定介面。
- `features/audio/`：原創合成的選兵、腳步、攻擊、命中、施法與勝利音效。

尋路、距離與碰撞在平面邏輯座標運算；畫面另投影成 2:1 等角座標。單位以腳底位置排序，碰撞邊界預留足夠間距以避免轉角卡住。Runtime HP、MP、冷卻、命令和目標不寫回共用定義資源。

## 第一階段界線
