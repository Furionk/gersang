左上餅乾表示主角體力，10 HP = 1 心，保留小數。超過五心時分組顯示，每枚容量與實際剩餘心數另列。中央為真實關卡時間，右上為五件工具，右下為未捕捉數。概念圖的金幣沒有加入虛構數值或獎勵。

遊戲中 1–5／滾輪直接換裝；可見游標時也能點右上圖示。Q／左下按鈕開啟道具輪盤，暫停時間與角色／猴子模擬。輪盤中 1–5／滾輪／點圖示預覽，Enter／黃色裝備按鈕確認，Q／Esc／紅色關閉取消。選單清除移動、瞄準和使用工具輸入；換裝不能取消已開始的揮擊，於收招後生效。

進入 3D 的鏡頭展示後自動 3、2、1、開始，不再彈出首次確認視窗。河灣接近與原有遭遇倒數沿用。Web 現預設自由滑鼠鏡頭，首次點擊畫面取得 Pointer Lock 並消耗該次點擊，不會誤出手；不支援鎖定的內嵌瀏覽器仍可在 Esc 設定啟用右鍵拖曳／方向鍵鏡頭備援。Esc／失焦仍暫停；進場倒數遇失焦也會停住。暫停設定仍可切換鎖定滑鼠模式。

介面以比例縮放，Web 額外留 52 像素頂部工具列空間。桌面鍵鼠為驗收範圍；窄側欄能縮放顯示，但不是手機觸控版。
