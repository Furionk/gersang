# 戰鬥 V2 操作與技能設定

**操作已由2026-10-09 V3取代**：全部技能冷卻0、每次手動技能皆需左鍵確認、自身技也需確認；按住／Ctrl連射取消，E只準備；恢復／補魔可右鍵自動切換，F1鎖游標。請讀 [最新操作](combat_controls.md)。下方舊操作保留作歷史背景；技能效果與數值章節仍可參考。角色視窗亦以 character_sheet_guide.md 為準。

## 開始試玩

使用 Godot 4.7.1 開啟此專案，按 F5。上方「草原／山道／洞窟」直接進入戰場；行旅點怪也能經三秒倒數進戰。左鍵選兵、拖框多選、Shift 加選；右鍵移動／指定攻擊。M/A/S/H 為移動、攻擊、停止、駐守，Ctrl＋數字存編隊、數字召回、Tab 全選。

右下只顯示目前所選單位的技能。多選取技能合集，同技能合併一格；tooltip 顯示 MP、冷卻、可用人數、公式及不可用原因。被動／自動技能不能手動按。切換選兵會停止已失去施法者的連射和瞄準。

技能圖示在滑鼠按下時響應；快捷鍵在按下時響應。即時自身技不用再點地面，其他技能左鍵確認；無效目標不扣 MP 且保留瞄準。右鍵／Esc取消瞄準。

按住技能鍵可在確認目標後連射；Ctrl＋技能鍵／圖示可預約連射。E依已設定的「兵＋技能」順序發出下一項合法技能，不依賴目前選取部隊。點 E 列可排序所有主動技能，包含同一兵的多個技能。

手動技能前搖預設為0，於下一個60Hz邏輯更新立即執行，沒有統一0.5秒等待；資源仍可設定非零前搖。新合法技能可中斷未完成的舊命令；無效命令不會先打斷原有動作。自訂前搖在開始時扣 MP，主動中斷不退 MP；目標在前搖中失效則退回未釋放的 MP。

怪物進戰第三秒開始全場索敵，此後每三秒補找失效目標；已鎖定目標持續追擊／攻擊，不等三秒才移動。友軍基本索敵維持原有偵測半徑。冰牆只阻擋地面移動，不擋箭和法術。

2026-10-08 修正：路徑暫時被冰牆／地形／擁擠阻塞時，追擊與施法接近會保留原命令，進入 `blocked` 狀態並以約0.75–0.87秒間隔重試。導航圖更新（例如冰牆消失）或目標位置明顯改變會解除等待，重新尋路；不會因卡住兩秒就永久停住。怪物仍保留三秒全場索敵節奏，但原目標不在攻擊範圍時，會每0.24秒檢查是否已有其他對手進入攻擊範圍，優先近身反擊。普通移動命令在目的地不可達時仍停止並提示。

## 行旅選兵、能力與背包（2026-10-08）

大地圖 HUD 更新：以附圖的1024×768比例作基準，左側12格中目前7格為已擁有隊員，5格保留招募位。頭像使用獨立立繪图集的臉部區域，下方雙條為真正HP／MP；有配點才顯示＋，點＋開能力，不自動分配。點頭像會選兵并展開右側完整立繪。

右上小地圖使用原創繪圖与主角臉部位置標記，跟随當前邏輯座標，可放大／縮小、開大地圖；M切換完整地圖。地圖對應本機試作範圍與五個地點標記，不是已建成的國家交通網，也不能靠點地圖瞬移。底部由主角資料、訊息區与視窗圖示三區組成；沒有飽食度。戰鬥力／信用算法待提供，銀兩系統未接，均顯示—而非編造數值。

右下背包、能力、裝備、地圖、說明、商團、朋友、設定圖示均可點擊。商團／朋友／交易／和平模式目前只展示誠實的單機未連線狀態，沒有網路發送。訊息輸入Enter只寫本機log，文字以字面顯示，不執行BBCode。設定保留試玩入口；非戰鬥不再顯示頂部開發者條。

独立美術在 `art/ui/classic/`，可透過兵種Inspector的portrait_path／standee_path指定自己的PNG；未指定時用本輪七人立繪圖集和illustration_index。不改戰鬥sprite、動畫或原美術。提示詞、版本與限制見 `docs/world_hud_art_manifest.json`。重繪素材不宣稱與原作100%像素相同。

非戰鬥時點左側肖像或1–7選兵；S切換左側能力面板、I切換右側背包，可同時開啟。再次按同鍵關閉對應面板，Esc先關閉這兩張面板；點介面不發地面命令。倒數進戰會關閉面板。戰鬥中 S 保持停止命令，I保持既有技能綁定，不改成背包。

主角與六名傭兵都有獨立經驗、配點、HP／MP、十格背包與四個裝備格。點背包裝備會裝到對應格，點裝備格卸下；點飯糰／茶恢復所選兵，不是只作用主角。已滿不消耗，背包／負重不足不會部分扣除或遺失裝備。初次建立角色送測試裝備與補給；舊角色不重複派發。

使用資料站的**累計經驗欄** Lv.1–100，封頂100，Lv.100累計18,350,220。來源的下一級欄與累計欄有幾处差異，本版不自行修補／重算，以累計欄原值為準：[經驗表來源](https://www.52jushang.com/qita/zhandou_exp.asp)。每級4配點，可按＋分配力量／敏捷／智力／幸運；一次獎勵可連升多級。

每隻敵人的 `UnitDefinition.experience_reward` 預設20，可在兵種資源調整。勝利把本場被擊殺敵人的經驗合計分給參戰永久隊員（包含戰鬥中倒下者），整數餘數依隊伍順序補發；不重複結算。失敗、撤退和壓力測試不發經驗。尚未模仿原作殺怪經驗分配公式，也未加入信用度／轉職。倒下隊員戰後以1HP復甦供本機試玩，升級不自動回滿體力／法力。

### 數值與試玩公式

`common/data/unit_definition.gd` 是角色基礎；`features/progression/data/stat_rules.tres` 是共用係數，亦可替單一兵種指定其他 `stat_rules`。以下是**可調預設，並非原作量測值**。令S／A／I／L為含配點與裝備的力量／敏捷／智力／幸運，n=等級−1，所有裝備同類加值加總一次：

| 數值 | 預設推導 |
| --- | --- |
| 攻擊均值 | 基礎damage＋1.5×(S−20)＋0.35×n＋裝備攻擊；實際普攻抽±10% |
| 防禦均值 | 基礎defense＋0.25×(S−20)＋0.25×n＋裝備防禦；抽±20% |
| 命中 | 基礎accuracy＋2×A＋L＋裝備命中；抽±5% |
| 閃避 | 基礎evasion＋3%＋0.1%×(A−20)＋0.1%×(L−20)＋裝備閃避，限制0–80% |
| 自然暴擊 | 2%＋0.1%×(L−20)＋裝備暴擊，限制0–100% |
| 戰鬥移速 | 基礎speed×clamp(1＋0.003×(A−20),0.2,3)＋裝備速度；再套手感倍率與減速 |
| 最大體力 | 基礎max_health＋4×(S−20)＋8×n＋裝備體力 |
| 最大法力 | 基礎max_mana＋3×(I−20)＋2×n＋裝備法力 |
| 法術抵抗 | 基礎magic_resistance＋裝備法抗，限制0–90% |

屬性基準20用來保留已調過的初始兵種差異；低能力值／過度減值不會造成負HP、負攻防或負速度。行旅仍用原先移速，敏捷增速作用戰鬥部隊。

普攻命中機率=clamp(98%＋0.001×(本次命中抽值−對方命中均值)−對方閃避,5%,100%)。失敗顯示MISS且不扣HP。自然暴擊把本次傷害乘2；配置的一擊必殺另按其機率和MP規則，以技能公式取代傷害，已觸發時不再疊加自然暴擊。

物理傷害=max(0,傷害−本次防禦抽值)×(1−armor)，減免只套一次。法術傷害=傷害×(1−法抗)，不再套物理防禦／armor。技能資源有 `damage_type`：暴雷、地震、車輪預設物理，火龍／雷擊預設法術。範圍法術目前必中，不使用普攻命中／自然暴擊抽值；技能公式仍定義每個實際命中／tick的基礎傷害。

技能公式新增 `luck`／`幸運`／`幸运`，例如 `力量*2+幸運`。Inspector試算增加幸運、固定防禦、物理抵抗和法抗，按技能傷害類型顯示減傷結果。

### 背包與存檔

測試物品資源：`features/progression/data/items/`，可調裝備格、weight、消耗品／素材的max_stack、restore及modifiers；裝備一律以單件保存，避免裝備堆疊造成遺失。短刃加力量／攻擊，布甲加防禦／體力，方士巾加智力／法抗，玉佩加幸運；飯糰補HP、茶補MP。裝備加成不改寫共用兵種資源。

養成存檔為 `user://party_progress.dat`，包含版本、固定隊員識別、累計經驗、已分配點、裝備ID、背包數量及HP／MP。更動配點／裝備／補給與戰鬥結算會保存；臨時控制、減速、召喚和冷卻不存。先寫暫存檔，原檔移到 `.bak` 再替換。格式有誤／新版本不相容時保留原檔並禁止覆寫，可讀取可用備份供本次試玩。**沒有遊戲內刪檔／重置角色功能。**

所有 `res://tests/` 命令列測試自動隔離，不讀寫玩家正式養成檔；永久存檔測試另用唯一命名的user://測試檔。

## 在 Godot Inspector 分配技能

1. 開啟 `features/units/data/` 的兵種 .tres。
2. 在 `skills` 陣列加入或移除 `features/skills/data/` 的技能資源。
3. 編輯力量、敏捷、體質、智慧／智力和等級；四項能力預設20、等級1。既有 `damage` 是公式中的攻擊力。
4. 開啟技能 .tres，調整目標類型、觸發方式、MP、冷卻、射程、前搖、公式和 `effect_data`。
5. 在 `effect_data` 調整半徑、壽命、tick間隔、減速、牆長、火龍速度／拖尾及召喚模板。
6. 儲存，重新執行專案。既有玩家快捷鍵設定優先於資源中的預設鍵。

啟用的 `Skill Formula Preview` 外掛會在技能 Inspector 上方提供能力值、目標 armor 和公式結果。若未顯示，檢查 Project Settings → Plugins 中此外掛已啟用。

## 傷害公式

支援：
- 力量／strength
- 傷害／攻擊力／attack
- 智慧／智力／intelligence
- 敏捷／agility、體質／vitality、等級／level
- 數字、括號、`+ - * /`，亦可輸入 `× ÷`

例如力量20、攻擊24、智力30、等級10：

| 公式 | 基礎結果 |
| --- | --- |
| 力量×2 | 40 |
| 傷害*2 | 48 |
| 智慧*2 | 60 |
| (attack+level)*2 | 68 |

公式是每次實際命中／tick的基礎傷害，之後只套用一次現有 armor：`raw*(1-clamp(armor,0,0.9))`。負值按0處理，未知變數、函式、物件呼叫、除零和非有限值禁止施放。持續技能在釋放時保存能力快照，不會因修改模板影響已發出的傷害。

地震結束後才套用減速；同類減速取最強並刷新持續時間，不疊乘，不改兵種原始速度。箭魂是獨立單位，可選取和全選，不占永久肖像／編隊容量；死亡、超時、離場會清理。冰牆採占格計數，重疊牆不會因一面消失而全部開路。
