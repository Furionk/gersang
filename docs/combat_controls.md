# 最新戰鬥操作（V3）

停止舊遊戲後重新F5。這頁取代 V2 的連射／冷卻操作；2026-10-10 D17把暴雷擊改為按鍵／圖示即放，其餘手動技仍需左鍵確認。

## 操作

- **F1**：大地圖、倒數及戰鬥皆可鎖住可見游標，再按F1解鎖。包含操作GUI的整個遊戲視窗，而不是只限地形區。切地圖／進戰保留session偏好；失焦／選單／載入／戰果暫釋放，回焦／關選單／返回大地圖或戰場恢復。退出遊戲完全清除。
- **一般技能鍵 → 左鍵 → 施法**。火龍是 R → 左鍵地點，下一次再R → 左鍵。**暴雷擊例外：I或點圖示立即以自身為中心施放，不需左鍵**；再按I可再施放，但不能按住連射。爆破從固定格點由內到外形成等角圓，不跟隨角色／不把sprite沿半徑移動。
- 目前全部技能 **冷卻0**。仍要足夠MP，且保留自訂前搖、召喚上限、實際效果持續時間；普攻攻擊間隔沒有改成0。
- 按住、Ctrl及舊連射設定不再重放上一個目標。**E**可按既有序列準備下一名可用施法者，會切選該兵，然後左鍵確認。
- **恢復 K／補給 F**：左鍵技能圖示或快捷鍵準備，再點友軍。**右鍵圖示切換自動**；標示自動／手動／混合，開啟時底色變綠。恢復預設自動，補給預設手動。缺魔時仍能關閉自動。
- 自動治療／補魔只作用附近存活同隊、有缺血／缺魔者；不追遠距目標，也不自動對自己補魔。可以暫停當前攻擊、補給後繼續原攻擊；不打斷明示移動或施法。
- 單位指向法術沒有指向圈；合法單位被點擊會短暫閃爍。普通右键指定敵人攻擊也同樣閃爍，確認命令指向誰，不保證已命中。
- 右鍵／Esc取消瞄準；尚未瞄準時右鍵敵人是指定攻擊。原來的框選、加選、編隊、移動／停止／駐守不改。

## 設定與界限

SkillDefinition.cooldown全部現有資源為0；没有隱藏的repeat_interval冷卻。cast_time控制前搖，SkillEffectDefinition.duration/tick_interval控制效果。恢復／補魔的模式由每個場內AbilityController管理，換選兵不會丟失，也不改共有.tres；新戰鬥回到預設。

F1採Godot的可見視窗限制模式。[官方Input說明](https://docs.godotengine.org/en/stable/classes/class_input.html#enum-input-mousemode)。在Godot內嵌Game面板遇到平台／嵌入限制時，先用獨立遊戲視窗測試；此輪自動驗證的是模式、焦點及轉場生命週期，未把實體鼠標拖曳出界當成已人工驗收。

詳細證據見 [驗證](combat_controls_validation.md)，程式接口與防回退契約見 [規格](../specs/combat_controls.md)。

新戰鬥HUD／胜利卷軸是 [D16介面規格](../specs/battle_presentation.md)：2秒保留戰場後顯示卷軸，再3秒回圖，卷軸期間左鍵快回。D17暴雷新增44項實際渲染／輸入與靜態爆破格點檢查，圖在artifacts/world/blast-layer-0..4.png；正式完成狀態仍按最新結果JSON及文件差異，不沿用舊V3驗證報告冒充當輪結果。
