# 彩虹冒險：火龍神殿動作地城

## 十二區與手機操作改版（2026-10-16，目前版本）

本節取代下方歷史版本的區域數、怪隊數及固定出招順序。原生場景擴為 5120×6400、十二個主題區、左右迴環與跨區捷徑，共 36 支怪隊（28 普通／精英、8 明確點選的 Boss 入口）。建議等級 25／50／75／90，沒有等級或通關鎖；原始入口、安全返回點與穩定 ID 保留。

手機使用獨立 `touch_router.gd`：左側48%非 UI 區域按下生成搖桿、15%死區、類比速度、超出半徑仍保持輸入；基座只在本次觸摸期間固定。每指獨立持有，支援移動同時攻擊／防禦；放開、取消、失焦、切角、旋轉及離場清除狀態。右側十字上遠攻、右近攻、左防禦、下加速，按物理 DPI／視窗比例換算76／64dp目標及間距，避開安全區。下方編隊可滑動，拖曳不選角；遠攻拖曳超過12dp覆蓋前方45度的視線輔助瞄準。觸控配置可手動開關，鍵盤／手把仍保留。

新增地獄犬、雙頭犬、熔岩巨魔、熔翼蝠，分別追擊、側面夾擊、慢速近戰壓迫、遠攻游走，混編進入不同怪區。新增原創四方向 atlas、三種高階火龍輪廓與四類地標；方向以 SpriteSheetLayout 配置，動作沿用程序式揮動／位移。**這批新素材不是每個動作都重繪逐幀的完整動畫表。** 原始透明 PNG 保留，來源與雜湊見驗收資料。

火龍由 `dragon_tier_0..3.tres` 定義推薦等級、權重招式池、有限連續次數、4.5／3.5／2.6／1.8秒間隔。三階段、二段追擊、掃射、扇形彈、衝撞尾跡、旋轉缺口火環及螺旋彈依階級增加。招式採遭遇種子，可重現；固定落點公布後不追蹤。火彈是共享鎖定折線的定時取樣傷害，每顆對每位角色最多命中一次。高階第三組攻勢後仍有明確反擊窗口。

祭司1／2／4／8隻各自有HP；兩隻最多一位主要施法者，四／八隻最多兩位，八隻另分兩組輪替。重組有1.5秒提示，死者方位留下缺口；隊伍共享儀式換息，避免各自技能把反擊時間完全覆蓋。陣形落點檢查完整身體與原生障礙，避免大型角色卡牆。HUD 只顯示存活數、當前目標與其HP，不堆八條大型框。

`attack_schedule.gd` 以0.15秒時間步、八方向及等待、24條候選路徑檢查未來危險，計入當前收招延遲、普通走速、角色半徑、原生地形與既有大型身體。無路可達時延後／拒絕低優先候選攻勢，預警與命中共用幾何資料。這是保守的有限搜尋；不是連續物理與未來動態身體的數學無傷證明。隊友只讀已公布的危險區，也可能閃避失敗。

原有編隊、裝備、背包、擊殺紀錄保留；新增槽位與數值修訂在探索狀態才套用，受傷比例保留。一般區域不啟用這套動作控制器。實際玩家不會被自動升級或補血；等級與初始滿血只用於獨立測試夾具。

驗證命令：`python tools/run_rainbow_overhaul.py <suite> [--render]`；自然戰鬥可加 `--level=90 --habitat=rainbow_fire_dragon_tier_3 --seed=55049 --idle`。單場新鮮編隊用來量測時間；連續三戰不補血，敗北同樣必須正確結算與返回。完整結果、已知舊回歸失敗、手機／人工未驗收項目見 `artifacts/rainbow-overhaul/validation.md`。

## 怪物與Boss機制

- 史萊姆：慢速近攻與腳下熔泡，75半徑、1.4秒固定位置預警、24技能威力，側移可避開。
- 熔岩獸：重近攻與260距離、半角0.55弧度的裂地猛踏；1.3秒預警、65技能威力，繞側後反擊。
- 祭司：三發扇形火符；烙印最多標記3名分散隊員，65%HP以下最多5名，位置鎖定後1.6秒爆發（95半徑、85威力）。下一招焚魂外環為145內圈安全／370外半徑，1.8秒預警、102威力。每兩次大招後耗竭4秒，承傷由0.8倍改為1.6倍。
- 火龍：HP65%／35%切換二、三階段。固定循環「灼世吐息→熔星墜落→龍心爆燃」。吐息距離620，半角隨階段0.57／0.66／0.75，1.6秒鎖向預警、100威力；地形可擋。熔星標記最多3／4／5名分散隊員，115半徑、1.8秒預警、80威力。龍心爆燃為170內圈安全／520外半徑，2.1秒預警、130威力；結束破鱗5秒，承傷由0.8倍改為1.8倍，停止出招提供反擊窗口。

以上是依參考圖與動作玩法創作的機制，並非宣稱逐幀還原原作數值。紅色區域是危險、青色內圈是安全。預警出現後不追蹤玩家；每次爆發只判定一次傷害，渲染幀不追加傷害。圓環採真正環形幾何，視覺與傷害共用相同參數。

兩王平時抗硬直及擊退，破防時可受硬直但始終不會被推飛。AI隊員在預警區中尋找原生導航可達的安全位置，使用同樣BP加速撤離，保留收招代價；主控由玩家自行判斷。Boss死亡立即清除其未發動機制，離場清理所有狀態。Boss血條、階段及當前應對提示隨螢幕寬度重排。

`features/rainbow/data/enemies/*.tres`為獨立Monster Pattern／Weapon數值入口；`temple_mechanics.gd`管理單場機制。單位正式數值在`features/units/data/monsters/`。四張新透明圖集共64個繪製姿勢，四朝向映射八方向；獸與龍的西北攻擊使用原生clip鏡像覆蓋。出招／施法共用攻擊格，死亡仍為原生旋轉淡出，沒有獨立死亡逐格圖。

原生地板、兩種法陣、火盆與龍骨門均已整合；戰場Ground在Z=-3500、地面法陣-3200、預警-100、角色0，避免預警被地板遮住。新場景與資源可直接在Godot編輯，啟動時不重建地圖。一次性製作工具`expand_rainbow_dungeon.gd`、`dress_rainbow_dungeon.gd`、`repair_rainbow_native_refs.gd`與`tune_rainbow_dungeon.py`都拒絕覆蓋已完成版本。

## 試玩

以 Godot 4.7.1 開啟專案並執行 `main.tscn`。在青嶺河灣的地圖／入口清單選「彩虹冒險 · 火龍神殿」，或點擊對應地城門。入口邏輯座標約 `(4694, 2318)`，有經既有導航驗證的抵達路徑。

進入後點擊怪隊並靠近，沿用五秒遭遇倒數。進戰預設操作編隊主角，其餘現有出戰隊員交給AI。獲勝沿用兩秒收尾與三秒結算畫面，自動返回遇敵位置；前庭出口返回河灣。撤退與敗北沿用既有結算及安全返回規則。

| 操作 | 功能 |
|---|---|
| 方向鍵／左側虛擬搖桿／手把左類比 | 依畫面方向直接移動、更新攻擊方向 |
| A／加速按鈕／手把左肩 | 按住加速，消耗目前角色 BP |
| S／近攻按鈕／手把 A | 有起手與收招的方向扇形近戰；鍵盤及畫面按鈕可按住連攻 |
| D／遠攻按鈕／手把 X | 沿角色朝向射出有碰撞的投射物，依兵種消耗 2–7 MP；鍵盤及畫面按鈕可按住連射 |
| 空白／防禦按鈕／手把 B | 短時間正面防禦，消耗 12 BP |
| 隊員按鈕／場上點選／數字鍵／Tab／手把右肩 | 切換操控；保留每人 HP、MP、BP、起手、收招與受擊狀態 |
| Esc／撤退按鈕 | 沿原有結算程序撤退 |

AI 在隊長附近尋敵作戰，過遠則沿原生導航回到隊形位置，近戰與遠戰共用玩家的攻擊、碰撞和傷害規則。主控倒下後自動選下一位存活可控隊員。此切片沒有把原 RTS 技能快捷鍵搬進動作模式。

## 操作與命中回饋打磨

編隊改為底部橫向列，保留數字鍵與 Tab；顯示操控中／AI 跟隨／已倒下及每人血條。左上改為目前角色 HP／MP／BP；右上顯示剩餘敵軍與「擬聲」「震動」開關。按鈕顯示收招秒數或 MP／BP 不足，滑鼠停留可看操作提示。戰鬥結束顯示「敵軍全滅 · 即將結算」。

近戰有交替方向的實心刀光；實際造成傷害才觸發十字火花、擴散碎光、100ms 角色閃光與約45ms局部頓挫。沒有修改 Engine.time_scale；受擊與出手角色局部停頓，世界流程與介面正常運作。鏡頭回饋最大2.5邏輯像素，可隨時關閉，回圖清零。

收招最後180ms與命中停頓可緩衝一次下一招；切換角色清掉原操控者的待發指令，原起手／收招仍保留。鍵盤與畫面按鈕可按住近攻／遠攻，仍逐次走起手、收招、MP與命中判定。三段刀光及聲音為呈現節奏，沒有第三段額外傷害倍率；兵種間的倍率差異明確存於各自 Weapon Resource。遠程 AI 缺乏施放 MP 時改用近攻。

四個新短促擬聲 TTS 為「切／劈／砰／破」，沿用既有授權 ElevenLabs Arthur 中文聲線，作為共通漫畫擬聲層，不改兵種原有聲線資產。主控實際命中才觸發，單一聲道中斷／重播，不堆疊長句；AI 只使用較低音量的打擊音效。另製作六個原創瞬態音效，區分揮空、切斬、重劈、彈丸、重擊及格擋。

聲音位於 `features/rainbow/audio/`，來源與長度／SHA-256 見 `provenance.json`；生成工具 `tools/rainbow_combat_audio.py` 緩存原始結果，未知請求結果不自動重發。遊戲只播放本地素材，不連線合成。新音效由 `action_feedback.gd` 限流播放，TTS 沿用 UnitVoice 全域靜音／音量；本場開關不改其他模式偏好。主觀音色仍可再調整，未宣稱人工聆聽驗收。

新增驗證涵蓋命中／揮空區別、實際 shader、局部頓挫、輸入緩衝一次釋放、按住連攻、切換不帶出舊指令、底部布局、視窗尺寸及音訊匯流排輸出。打磨交付證據另存 `artifacts/rainbow-polish/`。

`features/rainbow/data/weapons/*.tres` 是上述數值與圖像的原生編輯入口，`default_action.tres` 明確列出11個引用。傷害仍以原角色派生攻擊乘武器倍率，交給既有傷害服務；爆裂次要目標為55%倍率且逐一檢查牆體遮擋。貫穿每個目標只命中一次，AI 使用相同時序、耗魔與碰撞。醫術師在這套兩鍵動作模式的遠攻是飛針，並非新增自動治療技能。原 RTS 技能沒有變更。

新美術透過 `UnitView.set_action_skin` 只覆寫該遭遇視圖，從不修改共享 UnitDefinition、CharacterRecord、等級、技能、編隊或儲存ID。一般區域保持原本外觀與RTS。底部肖像、左上角色專長與 S／D 按鈕同步顯示新造型和招式；提示可查看起手／收招及耗魔。

地板使用兩張原創材質打包成64×32與80×40原生TileSet；每種尺寸128個跨格連續變體。早期美術替換保留導航；後續經使用者授權擴建三座大殿與原生戰場。原前庭通行與既有戰場幾何仍保留；新增導航見上方地城說明。沒有啟動時重建或隨機刷地圖。

素材來源、提示詞、原始PNG雜湊與檢閱畫面見 `artifacts/rainbow-content/`。`tools/author_rainbow_skins.py`、`author_rainbow_weapons.py`、`author_rainbow_terrain.gd` 為一次性製作紀錄，遇到已存在的正式新內容會拒絕重跑；日後直接編輯原生Resource與場景。

執行 `python tools/run_rainbow_checks.py rainbow_content_suite --render` 可驗證新圖集、11兵種真實攻擊、彈道遮擋、導航保留及完整動作遭遇流程；它以 `artifacts/rainbow-content/before/` 的原生地圖快照檢查保留項目。此為本機自動輸入與實際渲染證據，尚未人工驗收手把、觸控或Web版本。

## 範圍與原生編輯

- 只有遇敵快照的返回地圖在 `RainbowActionProfile.allowed_maps` 且遭遇有 `action_profile` 才啟用。一般戰場、試兵與其餘地城仍走原 RTS 控制。
- `features/world/data/rainbow_temple.tscn`：原生探索 TileMap、入口／出口、安全區及 MonsterRegions。河灣原內容保留，僅追加入口和分離的返回落腳點。
- `features/battle/maps/rainbow_temple.tscn`：原生 Ground／Walkable／Blockers 與五個 SpawnZones。
- `features/world/data/rainbow_temple_arena.tres`：戰場與動作 profile 連結。
- `features/rainbow/data/default_action.tres`：可在 Inspector 編輯加速度、BP、近遠攻時間、範圍、射速、防禦與跟隨距離。未覆寫值使用 `action_profile.gd` 預設。
- `features/units/data/monsters/rainbow_slime.tres`：獨立穩定 ID，保留原有轉珠怪 Resource；新史萊姆不觸發轉珠模式。
- `action_actor.gd` 持有每角色狀態；`action_battle.gd` 負責輸入擁有者、AI 與命中；`action_hud.gd`／`action_stick.gd`／`action_visual.gd` 處理呈現。

位置與物理仍使用原專案邏輯 XY，畫面輸入經 `Iso.unproject` 轉換；身體與鏡頭共用 `WorldVisualPose`。傷害交給 `GameDirector.apply_damage`／`UnitVitals`，獎勵與磁碟保存仍由 `SettlementService` 提交完整快照及冪等收據。切換角色不複製實體、不重建數據。

`tools/author_rainbow_encounter.gd` 只保留首次建立的來源；偵測到場景已存在即拒絕執行。後續直接編輯原生場景，不重新生成覆蓋美術修改。
