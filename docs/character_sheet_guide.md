# 角色行囊、能力及技能

非戰鬥點左側肖像，或按 **I**，開啟角色全畫面。中央是原創全身立繪，不再疊出獨立立繪視窗。

- 左側兵種列或 1–7：換選兵，裝備、物品與技能同步換人。
- **I 裝備**：左頭盔／武器／衣甲，右手套／腰帶／符咒，下左戒指／鞋履／右戒指。
- 右下10格行囊：點擊裝備或使用；點身體裝備格卸下。仍檢查負重、背包空間及等級。
- **S 能力**：顯示經驗、能力、剩餘點數與派生戰鬥數值。加號 +1；**Shift＋點加號 +100**，不足100就分配餘下點數，不透支。
- 按目前模式的 I／S 可關閉；X／Esc 也會先關此畫面。戰鬥中的 S／I 操作保持原樣。
- **F2**：開物品 Debug，與角色畫面互斥。可取得／直裝到選中兵；世界永久、戰鬥暫時規則未變。

右上只列這名兵真正擁有的技能，包括已裝備提供的技能。同技能只列一次。點圖示查看機制、觸發方式、目標、MP、冷卻、射程與來源；此處不施法。

金色區固定顯示目前數值代入公式、每次命中／tick 的基礎值及減傷結果。底下可調敵方防禦、物抗、法抗作試算，**不會修改角色或戰鬥敵人**。上方完整介紹可捲動；召喚、冰牆與回復有專屬說明，不顯示假傷害。

## Inspector 設定

兵種 `.tres` 的 skills 決定兵種技能；物品 `.tres` 的 granted_skills 提供裝備技能。SkillDefinition.description 是可選介紹；留空使用既有機制說明。damage_formula 仍是執行公式，支援中英文能力名；畫面不另存一份傷害算法。

GearItemDefinition.equipment_slot 現在提供九個位置。原先四項枚舉編號保留，舊存檔新增欄位預設空。尚未配置手套／腰帶／鞋／戒指資料，因此不會把招福玉佩假裝成那些裝備。

參考例：地震 `strength*0.5`；暴雷 `strength*2`；車輪 `attack*0.5`；火龍 `intelligence*0.5`。物理先減防禦再物抗，法術只用法抗。試算不是對未知敵人的最終保證傷害；命中、狀態、暴擊觸發和每跳實際目標仍由戰鬥處理。
