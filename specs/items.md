# 物品與 Debug v1

## 來源與範圍

52 巨商七個指定頁：食品、盔甲、刀劍、拐杖、槍矛、斧頭、火槍。六類裝備各五件，另首批五種食品。`sources/items52.json` 保存選取數據／圖網址；正式可編輯資料是 `features/progression/data/items/source52/*.tres`。

使用者最新決策：**一般食品只收錄名稱、重量、圖片，不設定食用效果，也不恢復飽食度。** `source_stats.satiety` 是來源紀錄，不是執行數值。舊 food/tea 是先前獨立的原型道具，與新食品分類不同。

## 契約

- ITEM-01：來源名稱、要求等級、重量、屬性／攻防區間和圖引用逐項可查。重量保留原始「斤」數字，對應專案負重單位，不擅自當 kg。
- ITEM-02：武器攻擊上下限是裝備加成，原角色能力值另算；不能改成假對稱區間。加成以同一 CombatStats 進入傷害及公式。
- ITEM-03：獨立背包／裝備／數量。共享 `.tres` 不存可變數量、HP、冷卻。新 ID 與旧角色存檔相容。
- ITEM-04：取得／直裝必須先驗負重、格數及裝備要求；失敗不吞物、不覆寫原裝備。Debug 可略過等級，但不能略過容量。
- ITEM-05：granted_skills 是可編輯 SkillDefinition 陣列。選兵技能欄、施法資格和被動同樣讀該集合；卸下／替換移除效果，不改 UnitDefinition。
- ITEM-06：大補丸重量0，只作用我方全隊，復活并加500HP／500MP，上限 clamp；不重建已消失召喚。經驗書重量0，只提升目標1級，Lv.100不消耗。
- ITEM-07：食品 NONE 不產生回血或消耗。滿值／滿級不消耗道具。
- ITEM-08：Debug F2／按鈕只在 debug build。世界操作目標是選取兵並可保存；戰鬥操作改副本，不能改入場快照或永久物品／經驗。正式遭遇結算不信任 Debug UI 提供的獎勵。
- ITEM-09：介面點擊不得發出地面命令；顯示實際目標、等級、負重、來源與資源路径。

高級長劍的爆雷擊、高級雙發鐵炮的一擊必殺連接既有本作技能。其公式／時序沿用可調本作值，不聲稱52原版量測。訓練拐杖暗黑火焰／訓練斧滿月舞只保留來源技能名稱，未連接的不能假顯示為已還原技能。10天到期、交易及職業完整限制不在本輪實作；allowed_roles 可配置。

`tests/items_suite.tscn` 驗證來源、數值／圖、指定兵、技能與移除、原子失敗、食品、復活、滿級、保存往返及戰鬥副本隔離。預設 MOVE 檢查不得刪除；--all 同時跑 items suite。
